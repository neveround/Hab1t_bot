# Habit Bot

Telegram-бот для учёта привычек на Python, aiogram 3 и асинхронном SQLAlchemy.

## Возможности

- Регистрация пользователя по Telegram ID
- Добавление привычек с описанием
- Просмотр списка привычек
- Отметка выполнения или пропуска
- Подсчёт текущей серии
- Статистика за последние 30 дней
- Напоминание каждый день в 09:00
- Проверка неотмеченных привычек в 23:00
- Еженедельная статистика по воскресеньям в 20:00

Время задач задаётся в `TIMEZONE` и по умолчанию установлено `Europe/Moscow`.

## Установка

Требуется Python 3.10 или новее.

1. Распакуй архив и открой папку проекта в терминале.
2. Создай виртуальное окружение:

   `python -m venv .venv`

3. Активируй его:

   Windows PowerShell: `.\.venv\Scripts\Activate.ps1`

   Windows CMD: `.\.venv\Scripts\activate.bat`

   macOS/Linux: `source .venv/bin/activate`

4. Установи зависимости:

   `pip install -r requirements.txt`

5. Скопируй `.env.example` в `.env`.
6. Вставь токен бота, полученный у @BotFather, в `BOT_TOKEN`.
7. Запусти:

   `python bot.py`

## Команды

- `/start` — открыть меню
- `/cancel` — отменить ввод привычки

## Структура

- `bot.py` — запуск приложения
- `config.py` — настройки
- `app/database.py` — подключение к SQLite
- `app/models.py` — таблицы пользователей, привычек и отметок
- `app/services.py` — бизнес-логика
- `app/handlers/` — обработчики Telegram
- `app/keyboards/` — inline-клавиатуры
- `app/scheduler/` — фоновые напоминания

## Важно

Не публикуй `.env` и не отправляй никому токен бота. Существующая база данных не удаляется автоматически. Если таблицы уже созданы, `create_all` создаст недостающие таблицы, но не изменит существующую структуру столбцов.
